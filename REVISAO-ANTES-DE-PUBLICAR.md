# Checklist de revisão antes da publicação

- [ ] Confirmar que a política da empresa e eventuais contratos permitem publicar estudos de caso derivados de experiências profissionais.
- [ ] Conferir se nenhum cliente, fornecedor, colaborador ou ambiente pode ser identificado.
- [ ] Conferir se não há IP interno, hostname, domínio privado, URL interna, nome de usuário ou topologia.
- [ ] Inspecionar PDFs e imagens, inclusive metadados e camadas de texto, antes de adicioná-los.
- [ ] Conferir se as ações descritas como executadas realmente foram executadas.
- [ ] Conferir se recomendações não foram apresentadas como resultados concluídos.
- [ ] Confirmar se a conclusão está limitada às evidências disponíveis.
- [ ] Revisar links e referências antes da publicação.
- [ ] Confirmar que o repositório contém somente arquivos que podem ser divulgados publicamente.
