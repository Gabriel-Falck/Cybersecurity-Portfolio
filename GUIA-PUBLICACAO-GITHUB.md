# Guia rápido — Publicar este portfólio no GitHub pelo navegador

Este pacote contém arquivos Markdown (`.md`). O GitHub renderiza esses arquivos como páginas formatadas automaticamente.

## 1. Criar o repositório

1. Entre em https://github.com e faça login.
2. Clique no sinal `+` no canto superior direito e escolha **New repository**.
3. Em **Repository name**, use `cybersecurity-portfolio`.
4. Em **Description**, use: `Portfólio técnico de Segurança da Informação — estudos de caso anonimizados.`
5. Selecione **Public** para que recrutadores possam acessar o conteúdo.
6. Deixe desmarcada a opção **Add a README file**, porque este pacote já contém o README principal que será enviado.
7. Clique em **Create repository**.

## 2. Enviar os arquivos

1. Abra o repositório recém-criado.
2. Escolha **Add file** e depois **Upload files**.
3. No computador, extraia o arquivo ZIP deste pacote.
4. Abra a pasta `cybersecurity-portfolio` extraída e arraste os arquivos e pastas para a área de upload do GitHub. Envie o conteúdo da pasta, não a pasta ZIP.
5. Confira se o `README.md` principal está na raiz e se existe a pasta `cases` com as seis subpastas.
6. Em **Commit changes**, escreva `Add initial cybersecurity portfolio` e confirme em **Commit changes**.

## 3. Conferir a publicação

Depois do envio, a página principal do repositório deve exibir o conteúdo de `README.md`. Abra cada pasta em `cases` para verificar sua respectiva página.

## 4. Adicionar os PDFs originais (opcional)

Os PDFs originais não estão incluídos neste pacote porque o material recebido nesta conversa foi o texto extraído dos documentos, não os arquivos PDF. Antes de publicar os PDFs, faça uma última revisão para remover metadados, imagens, nomes de arquivos, IPs, hostnames, domínios, horários e qualquer informação que possa identificar cliente ou ambiente.

Caso decida disponibilizar os PDFs, coloque cada arquivo na pasta do estudo correspondente e use nomes simples, por exemplo `estudo-de-caso.pdf`.

## 5. Link para o currículo

O endereço final seguirá este padrão:

`https://github.com/SEU-USUARIO/cybersecurity-portfolio`

Substitua `SEU-USUARIO` pelo seu nome de usuário real do GitHub. Não use o endereço ilustrativo no currículo antes de confirmar que o repositório está público e acessível.

## 6. Atenção antes de tornar público

- Não publique relatórios originais sem autorização para divulgação.
- Remova dados de clientes, ativos, redes internas, logs, prints e metadados identificáveis.
- Não publique credenciais, tokens, chaves, arquivos de configuração ou dados pessoais.
- Mantenha explícita a diferença entre ações executadas e recomendações propostas.
- Se houver dúvida sobre autorização de divulgação de um conteúdo derivado do trabalho, não publique esse detalhe.
